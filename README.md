## Attempts at sdn programming in a mininet


#### When sshing into the mininet vm
- ssh -Y mininet@localhost -p 2223

#### To ssh into ubuntu server vm
- ssh -Y ubuntu@192.168.56.102

#### When opening the mininet console
- sudo -E mn

#### To open terminal
- xterm h4


#### To spawn terminals for each mininet instance
- sudo -E mn -x
